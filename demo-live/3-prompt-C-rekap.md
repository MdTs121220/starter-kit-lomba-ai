# Prompt C — Tambah Satu Fitur: Rekap (Langkah 3)

Tempel di percakapan yang sama.

````text
Bagus. Sekarang tambahkan HANYA fitur F3: rekap bulanan per kelas.
Tampilkan jumlah H, I, S, A per siswa dan persentase hadir;
tandai merah kalau di bawah 75%. Jangan mengubah fitur yang sudah ada.
Tampilkan index.html lengkap yang sudah diperbarui dalam SATU blok.
````

## Setelah kode keluar
1. Copy kode → tempel **menimpa** seluruh isi `index.html` → Save.
2. Refresh browser (F5) → buka bagian rekap.
3. Pastikan data absen dari langkah 2 masih ada dan muncul di rekap.
